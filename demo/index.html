What this estimate means

The model was trained on California census block groups from 1990. It estimates the dataset’s capped median value target; it is not a current home-price estimate, appraisal, or investment advice.

The benchmark uses a geographic tile holdout. Its reported MLP holdout RMSE is about $70,000 and MAE about $49,000. A single prediction can be substantially wrong, especially in the highest-value band.
